## 🎛️ Switch Renderers Per App

The main idea behind Render-Switcher is simple: each app can use a different graphics renderer. Some apps behave better with Vulkan, while others are more stable or smoother with OpenGL. Instead of changing the whole device, you change one app at a time.

To switch a renderer:

1. Open the Render-Switcher WebUI from your module manager. Most module managers show a shortcut to the WebUI on the module card.
2. Look at the list of installed apps.
3. Tap the app you want to change.
4. Choose Vulkan or OpenGL for that app.
5. Save the change.
6. Close the app completely and open it again so the new renderer loads.

Your choices are remembered. When you open that app in the future, Render-Switcher applies the same renderer automatically. Other apps keep their own settings, so a change for one app never surprises you in another.

## 🛠️ Using the WebUI

The WebUI is the easiest way to use Render-Switcher. It is a small local page served by the module, so it works without an internet connection.

1. Open your module manager.
2. Find Render-Switcher in the module list.
3. Tap the WebUI button or the action button.
4. Wait a moment for the page to load.
5. Use the app list to review current renderer assignments.
6. Change, save, and reopen the app you edited.

If the WebUI does not open on the first try, close the module manager and open it again. Module managers sometimes need a fresh start before the local page responds.

## 📋 Supported Module Managers

Render-Switcher is packaged for three popular module managers:

- Magisk: enable Zygisk in the Magisk settings before installing.
- KernelSU: install through the Modules screen and reboot when prompted.
- APatch: install as a local module and reboot after the install completes.

Use only one module manager at a time. Installing the same module through two different managers can create confusing results.

## 🔄 Updating Render-Switcher

When a newer release appears on the download page, repeat the Windows transfer steps and install the new file over the old one. Your saved per-app choices stay in place after an update. Reboot after the update finishes so every app picks up the newest behavior.

## 🧹 Uninstalling

If you want to remove Render-Switcher, open your module manager, find the module, and choose Remove. Reboot the device afterward. Apps return to their default rendering behavior once the module is gone, and no leftover settings remain on your device.

## ❓ Troubleshooting

- The WebUI shows a blank page: close the module manager, reopen it, and tap the WebUI button again.
- An app looks wrong after a switch: open the WebUI, set that app back to its original renderer, and reopen the app.
- Nothing changed after installing: confirm the reboot actually completed and check that Zygisk is enabled in your module manager.
- The release file will not install: confirm you selected the file exactly as downloaded, without renaming or unpacking it.
- The device feels unstable after a change: revert the last app you edited, then reboot.

## 🛡️ Safety Tips

Change one app at a time and test it before moving on. Keep a note of the original setting for each app you edit so you can return to it quickly. Avoid changing system apps unless you have a clear reason and a recent backup. Use the official download link every time so you always receive the authentic release file.
